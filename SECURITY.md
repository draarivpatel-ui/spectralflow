# Security policy

Report suspected vulnerabilities through GitHub private vulnerability reporting in this repository. Include the affected version, a small reproduction and the observed impact.

## Scope

NACA geometry, imported checkpoints, lattice resource limits, numerical stability and finite telemetry exports are in scope, along with browser output escaping and accidental external network access. The browser application runs locally without runtime packages or remote services.

## Supported version

The current main branch receives fixes. Keep reports private until a correction is available and a disclosure date has been agreed.
